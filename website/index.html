AI PREDICTION

AI 智能分析 · 怎么预测、怎么验证

不是"感觉会涨"，而是明确的概率事件 + 可追溯的服务端台账 + 按真实交易日历的锁定与自动复盘，并用长期胜率回答"到底准不准"。

1
多目标预测上涨概率（未来 5/10/20 日收益超过 2%/5%/8%）、预期收益、超额收益、预期最大回撤、置信度——避免只学"涨或不涨"。
2
综合评分排名综合评分 = 35%×上涨概率 + 30%×预期收益 + 15%×超额收益 + 10%×行业强度 − 10%×风险；提供 7 种排名维度（综合 / 概率 / 收益 / 超额 / 风险收益比 / 高置信 / 低波动）。
3
按真实交易日历锁定开盘（9:30）后至收盘（15:00）前预测锁定、不可变更；收盘后至次日开盘前可重新预测。交易日按真实交易日历判定（由指数日K推导，自动识别春节/国庆等休市与调休），不会把假期当成交易日。
4
收盘自动复盘收盘后系统自动对照真实日K复盘当日预测：逐只判定命中/未中，统计命中率、预测收益与实际收益偏差、实际最大回撤，无需人工操作，并立即生成下一交易日预测。
5
长期可核验的胜率快照存于服务端台账（可跨设备、不因清缓存丢失），把多个交易日的预测汇总起来看累计命中率与滚动胜率趋势——单次预测只是样本，长期统计才能回答"这套模型到底准不准"。

REAL DATA

只用真实数据，绝不造假

本系统没有任何模拟数据：数据服务不可用时页面会明确报错，而不是展示假行情。

🌐 全市场真实行情

东方财富 clist 接口覆盖沪深主板 / 创业板 / 科创板 / 北交所约 5900 只股票，与同花顺股票列表一致，每 3 秒自动刷新。

📈 K 线 / 分钟线

日 / 周 / 月 K 线（前复权）与 5/15/30/60 分钟真实分钟线，本地缓存加速，二次打开秒回。

💰 财务 / 资金 / 分红

F10 主要财务指标、近 20 日资金流、分红送配与股息率推算，均来自东方财富公开接口并标注数据截止时间。

📰 新闻资讯

东方财富资讯搜索，标题为事实载体，情绪标签为规则模型推断并明确标注，绝不把事后信息当作预测时点已知信息。

🔒 预测可追溯

每次预测保存快照：预测日期、模型版本、数据截止时间、全部特征与市场环境，收盘后可按快照逐条复盘。

🛡️ 多源兜底

东财接口异常自动熔断切换备用源（push2delay / 腾讯），服务不中断；单只数据失败只影响该股票，页面明确标注。

GET STARTED

打开就能用

在线版直接访问，无需安装、无需注册账号、无需付费数据接口；也可在本地运行。

1
进入应用

点击页面上的「进入应用」按钮，或直接访问本站根路径 /（如 https://xinghuo1.org）。

2
一键体验

登录页点击「一键体验演示账号」即可进入；账号与自选股只保存在你自己的浏览器里。

3
看盘与选股

「大盘晴雨表」看市场总量，「榜单中心」看完整排行，「条件选股」按自己的条件筛股。

4
预测与复盘

「AI 智能分析」查看预测选股与个股诊断；每个交易日的预测都会锁定并存档，收盘后自动复盘，逐步积累累计胜率。

想在本地运行（数据不经第三方服务器）：安装 Node.js 16+，在 quantpick 目录双击 start.bat，然后访问 http://127.0.0.1:8090。

源码与完整文档在 GitHub：git clone https://github.com/G1G5-SYS/quantpick.git；有问题欢迎提 Issue。
